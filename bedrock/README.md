# Stone Golem — Bedrock edition

Add-on (behavior + resource pack) for Minecraft Bedrock **1.26.50+**, built on the stable Script API
(`@minecraft/server` 2.10.0) — no experimental toggles needed.

## Build

```bash
python3 bedrock/build.py   # -> bedrock/dist/StoneGolem-<version>.mcaddon
```

- All numbers: `bedrock/balance.json` (injected into `{{NAME}}` placeholders and `scripts/balance.js`).
- Textures come from the Java edition (`common/src/main/resources/...`, generated by `tools/generate_textures.py`).
- Pack sources: `bedrock/packs/BP` (entities, spawn rules, loot, item, script) and `bedrock/packs/RP`
  (client entities, geometry, animations, sounds, texts). Geometry and animations were converted from the Java model
  (Bedrock mirrors X and counts Y upwards: rotations become `(-x, -y, z)`); both can be edited in Blockbench.

## Install

Open the `.mcaddon` on the device (Minecraft imports both packs), then enable *Stone Golem* under
*Behavior Packs* and *Resource Packs* when creating or editing a world.

## Differences to the Java edition

- Same behaviour and numbers; the golem has no armor value (Bedrock mobs have no armor attribute), so it is a bit
  easier to hurt with ordinary weapons. Pickaxe ×2 / sword ×0.5 / projectile ×0.5 work via item tags
  (`minecraft:is_pickaxe`, `minecraft:is_sword`) in the damage sensor.
- The Golem Core tooltip is set on the dropped stack (localized); a Golem Core taken from the creative menu has none.
- Bedrock does not always report a player as the attacker of a hit; a melee hit without a known attacker targets the
  closest player within 6 blocks.

## Tests (development only)

`bedrock/tests/BP` holds GameTests (needs the *Beta APIs* experiment, so it is never part of the release). Setup on a
Bedrock Dedicated Server 1.26.52: add the BP, RP and test pack to a flat test world, enable Beta APIs, then in the
server console:

```
tickingarea add 90 -64 90 180 0 180 sgarena
fill 100 -61 100 123 -42 123 air
fill 100 -61 100 123 -61 123 stone
structure save stonegolem:arena 100 -61 100 123 -42 123 disk
execute positioned 140 -60 140 run gametest runset stonegolem
```

Simulated players are invisible to entity queries in the GameTest framework, so the rock test uses a husk as target;
the real player's flight height is a manual check.
